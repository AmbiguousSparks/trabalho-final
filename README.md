# 🎨 Projeto Final — Design System & UX

Este repositório contém o projeto desenvolvido como **trabalho final da disciplina de Design System & UX**. O objetivo foi aplicar os conceitos aprendidos em aula para construir um Design System completo, desde sua concepção no Figma até a implementação em uma aplicação React funcional.

## 🧩 Link do Design no Figma

Todo o sistema visual foi inicialmente projetado no Figma e pode ser acessado pelo link abaixo:

🔗 [Acesse o Design no Figma](https://www.figma.com/design/76iZt9R15IVhxSwSmyxLvm/Trabalho_DESIGN_SYSTEM?node-id=0-1&t=8QIL2vIqWnyhk7oy-1)


# 🚀 Como rodar o projeto localmente

Siga os passos abaixo para instalar e executar o projeto em sua máquina:

1. Clone o repositório

```bash

git clone https://github.com/seu-usuario/seu-repositorio.git
cd seu-repositorio

```

2. Instale as dependências

```bash

npm install

```

3. Execute o projeto em modo de desenvolvimento

```bash

npm run dev

```

A aplicação estará disponível em: http://localhost:5173

# 🧪 Testes

```bash

```

# 📚 Storybook

O Storybook foi utilizado para documentar e testar visualmente os componentes do Design System.

## Iniciar o Storybook

```bash

npm run storybook

```
Acesse em: http://localhost:6006

## Gerar build estática do Storybook

```bash

npm run build-storybook

```
# 🧹 Lint

Para verificar problemas de lint no código:


```bash

npm run lint

```

# 🛠️ Build de Produção

Para gerar a versão final da aplicação:

```bash

```

Para visualizar a build:

```bash

npm run preview

```

Este projeto foi desenvolvido com o intuito de demonstrar o processo completo de criação de um Design System, desde o planejamento visual no Figma até a implementação técnica com React e ferramentas modernas de desenvolvimento front-end.
